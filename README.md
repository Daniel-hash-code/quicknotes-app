# QuickNotes

QuickNotes is a simple, responsive web application for creating, organizing, searching and managing personal notes. Users can add notes under Personal, Work or Study categories, delete individual notes, search through their notes and clear all notes at once. Notes are stored in the browser using browser localStorage so they remain available after refreshing the page.

## Features

- Add notes with Personal, Work or Study categories
- Validate notes to prevent empty notes and notes longer than 200 characters
- Display the total number of notes
- Delete individual notes
- Search notes by their text
- Store notes in the browser using localStorage
- Clear all notes with a confirmation prompt
- Responsive layout for mobile and desktop screens
- Semantic HTML structure and accessible form labels

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in your code editor to run the application locally.
